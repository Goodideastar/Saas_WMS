## 项目经历

### WMS 仓储管理系统（Spring Boot 3.2 + Java 21 + Vue 3 + Docker Compose）

**角色：** 后端核心开发 / 独立部署上线

**项目简介：** 全栈 SaaS 仓储管理系统，支持产品管理、出入库订单、库存预警、数据看板及 AI 智能助手功能，已部署至阿里云生产环境。

**核心职责：**

1. 基于 MyBatis Plus 完成产品管理、出入库订单、库存预警、数据看板四大模块的 CRUD 开发，使用 LambdaQueryWrapper 实现动态条件查询，分页插件优化大数据量查询性能

2. 设计库存并发扣减方案：出库审核采用"行级锁 + 乐观锁"双重保障（SELECT FOR UPDATE + version 字段），防止超卖；入库审核通过 @Transactional 保证多步操作的原子性

3. 设计订单号生成策略（IN/OUT + yyyyMMdd + 4位序号），使用 Redisson 分布式锁（order-no-lock）解决高并发下单序号冲突问题

4. 基于 Spring Cache + Redis 实现多级缓存：用户权限缓存至 Redis（user:perm:{userId}）减少数据库查询，仪表盘统计数据 @Cacheable 缓存 1 小时，库存变更时 @CacheEvict 主动失效

5. 接入 AI 智能助手（AI Gateway），基于 LangGraph + FastAPI 构建自然语言数据查询能力，通过 SSE 流式返回 LLM 回答结果

6. 使用 Docker Compose 完成项目容器化部署，配置 MySQL 数据卷持久化、Redis AOF 持久化；阿里云 ECS 部署及运维（安全组配置、日志排查、服务重启）

## 技术亮点

- **高并发保障：** 出库审核采用数据库行级锁 + 乐观锁双重机制，Redisson 分布式锁生成唯一订单号，保障并发场景下数据一致性
- **缓存优化：** 用户权限和仪表盘统计数据缓存至 Redis，库存变更主动失效，减少数据库查询压力
- **部署运维：** 独立完成 Docker Compose 容器化部署和阿里云生产环境上线，具备 Linux 运维和故障排查能力
